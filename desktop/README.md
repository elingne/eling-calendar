# My Calendar 데스크톱 위젯

사이트(https://eling-calendar.ielingkk.workers.dev/)를 그대로 보여주는 얇은 데스크톱 창입니다. 일정·할 일·메모와 관리자 로그인은 전부 사이트가 맡고, 앱은 **창 모양**만 다룹니다. 그래서 웹과 데이터가 항상 같습니다.

## 할 수 있는 일

| 기능 | 사용법 |
| --- | --- |
| **항상 위에 두기** | 위쪽 📌 버튼(또는 트레이 메뉴 "항상 위에 두기"). 설정은 기억해요. |
| **위젯 ↔ 전체 전환** | 📌 옆 버튼. 위젯은 테두리 없는 작은 창(오늘 일정 + 지금 해야 하는 일), 전체는 웹 화면 그대로예요. 위젯의 위쪽 막대를 두 번 누르면 전체로 넓어져요. |
| **옮기기 / 크기 조절** | 위젯은 위쪽 막대를 끌어서 옮기고 가장자리를 끌어 크기를 바꿔요. 위치·크기는 모드마다 따로 기억해요. |
| **트레이로 숨기기** | 닫기(X), 최소화, 위젯의 — 버튼 모두 종료가 아니라 작업표시줄 알림 영역(트레이)으로 들어가요. 트레이 아이콘을 왼쪽 클릭하면 다시 나오고, 오른쪽 클릭하면 메뉴(열기/숨기기, 위젯·전체 모드, 항상 위, **종료**)가 나와요. |
| **실시간 연동** | 웹이나 다른 기기에서 일정·할 일·메모를 바꾸면 20초 안에 위젯에 반영돼요(반대도 같아요). 글을 쓰는 중이거나 끌어서 옮기는 중에는 화면을 새로 그리지 않고 끝나길 기다려요. |
| **한 번만 실행** | 이미 켜져 있을 때 또 실행하면 새 창 대신 기존 창이 나와요. |

처음 실행하면 전체 모드로 열려요. **관리자 로그인**(이메일 인증번호)을 한 번 하고, 위젯 버튼과 📌 버튼을 눌러 원하는 모양으로 맞추면 다음부터 그대로 열려요. 로그인 유지 기간은 사이트(Cloudflare Access) 설정을 따라요.

## 설치 파일 받기 (Rust 설치 없이)

1. `desktop-widget` 브랜치로 **Pull request를 열면** 자동으로 빌드가 시작돼요(저장소 → **Actions** → **Desktop app (Windows installer)**). `main`에 합친 뒤에는 같은 화면에서 **Run workflow**를 눌러 다시 만들 수 있어요.
2. 10~20분 뒤 실행 결과 맨 아래 **Artifacts → my-calendar-windows** 를 내려받아 압축을 풀고 `.exe` 설치 파일을 실행해요(관리자 권한 없이 현재 사용자에게 설치돼요).
3. Windows가 "알 수 없는 게시자" 경고를 띄우면 **추가 정보 → 실행**을 누르세요. 코드 서명을 하지 않은 개인용 설치 파일이라서 나오는 경고예요.

## 내 컴퓨터에서 직접 만들기

필요한 것: [Node.js 22 이상](https://nodejs.org/), [Rust](https://rustup.rs/), 그리고 Windows라면 [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)(Windows 11에는 들어 있어요)와 Visual Studio C++ Build Tools.

```powershell
cd desktop
npm install
npm run dev      # 개발용으로 바로 실행
npm run build    # 설치 파일 만들기 → src-tauri/target/release/bundle/
```

## 어떻게 동작하나요

- **창**: 처음에는 `dist/index.html`(작은 연결 확인 화면)이 열렸다가 인터넷이 되면 사이트로 이동해요. 인터넷이 없으면 5초마다 다시 시도해요.
- **로그인**: 사이트의 Cloudflare Access 로그인을 앱 창 안에서 그대로 써요. 앱에 비밀번호나 토큰을 따로 저장하지 않고, 보안 규칙(관리자 이메일 확인, 개인 기록 비공개)도 바뀌지 않아요.
- **앱이 사이트에 열어 준 것**: `get_state`, `set_mode`, `set_pinned`, `start_drag`, `hide_window` 다섯 가지뿐이에요(`src-tauri/build.rs`, `src-tauri/capabilities/main.json`). 파일·셸·네트워크 같은 권한은 주지 않았고, 이 사이트 주소에서만 쓸 수 있어요.
- **실시간**: 사이트가 일정·할 일·기록·메모를 저장할 때마다 서버의 변경 번호(`sync_state`)를 1씩 올려요. 화면이 보이는 동안 20초마다 이 번호만 확인하고, 바뀌었으면 화면을 새로 불러와요(`public/sync.js`). 내가 저장해서 올라간 번호는 알아보고 다시 불러오지 않아요. 숨겨진 창은 확인을 멈추고 다시 보이면 바로 확인해요.
- **저장 위치**: 창 위치·크기·모드는 앱 설정 폴더의 `window.json` 한 파일에만 저장해요(일정 데이터는 저장하지 않아요).

## 사이트 주소를 바꿀 때

주소는 두 곳에 있어요. 둘 다 같게 바꿔주세요.

- `dist/index.html` 의 `SITE_URL`
- `src-tauri/capabilities/main.json` 의 `remote.urls` (끝에 `/*` 유지)

## 알아둘 점

- 실시간은 20초 간격 확인이라 즉시는 아니에요. 더 빠르게 하려면 Cloudflare Durable Object 웹소켓으로 바꿀 수 있어요(Worker 설정 변경이 필요해서 이번에는 하지 않았어요).
- 위젯은 로그인한 관리자에게만 내용을 보여줘요. 로그인 전에는 안내와 로그인 버튼만 나와요.
- macOS·Linux용 설치 파일도 같은 코드로 만들 수 있지만 이번에는 Windows만 자동화했어요.

## 위젯 화면 (위젯 모드에서만 적용)
- 화면 전체를 줄여서(글자 포함) 작은 창에 맞췄어요. 스크롤바는 숨기고 휠·터치 스크롤은 그대로예요.
- 위쪽 막대: 📌 항상 위 · 캘린더↔메모 전환 · 전체 화면 · 숨기기.
- 캘린더 탭은 금주 메모 → 지금 해야 하는 일 → 일정 순이고, "지금 해야 하는 일" 옆 작은 버튼으로 "완료한 일"과 바꿔 봐요.
- 창 설정 `dragDropEnabled: false`: 켜져 있으면 Windows에서 웹 화면의 끌어서 순서 바꾸기가 막혀서 꺼뒀어요 (앱 재설치 필요).
